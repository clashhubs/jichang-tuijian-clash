1. **先按单 GB 成本圈出候选**——这是唯一能横向比较的硬指标，见下方表格
2. **再看运营连续性**——S/A/B/C/D 分档衡量的是「还开着的可能性」，与速度无关

## Clash 订阅怎么导入

拿到订阅链接后，三个主流客户端的操作：

### Clash Verge Rev
1. 打开 **订阅（Profiles）** 页
2. 顶部输入框粘贴订阅链接 → 点 **Import**
3. 导入后点该配置卡片使其生效，回到 **设置** 打开 **系统代理**

### Clash Meta / mihomo（内核）
配置文件里写入订阅地址，由内核定时拉取：

```yaml
proxy-providers:
  airport:
    type: http
    url: "你的订阅链接"
    interval: 3600
    path: ./providers/airport.yaml
    health-check:
      enable: true
      url: http://www.gstatic.com/generate_204
      interval: 300
```

### ClashX Meta（macOS）
菜单栏图标 → **配置** → **托管配置** → **管理** → 添加订阅链接 → 更新

**导入后节点全红或连不上**，先确认这三件事：订阅链接是否过期、客户端内核是否支持该协议（Hysteria2 / VLESS Reality 需要较新版本）、系统时间是否准确（偏差超过 90 秒会导致握手失败）。

## 两个价目表里藏着的问题

这两节是把 17 家的价目表并排放之后才看得出来的，单看任何一家的官网都发现不了。

### 一、性价比倒挂：买贵的档位，单价反而更高

正常的阶梯应该是买得越多单价越低。以下品牌存在**更贵的档位单 GB 成本反而高于便宜档位**的情况（差异超过 8% 才计入，避免把四舍五入说成问题）：

- **[唯兔云](https://clashhubs.net/reviews/weituyun/)**：进阶版（¥29.9/200GB = ¥0.149/GB） —— 该品牌最优档位是 ¥0.120/GB
- **[SOGO狗云](https://clashhubs.net/reviews/sogogouyun/)**：550G 档（¥80/550GB = ¥0.145/GB）、1.05T 档（¥150/1050GB = ¥0.143/GB） —— 该品牌最优档位是 ¥0.129/GB
- **[快狸](https://clashhubs.net/reviews/kuaili/)**：夜狸强化版（¥95/500GB = ¥0.190/GB）、天狸顶配版（¥180/1000GB = ¥0.180/GB） —— 该品牌最优档位是 ¥0.140/GB
- **[二猫云](https://clashhubs.net/reviews/ermaoyun/)**：橘猫畅玩版（¥40/230GB = ¥0.174/GB）、牛奶猫尊享版（¥80/430GB = ¥0.186/GB） —— 该品牌最优档位是 ¥0.154/GB

意味着这些档位**没有升级理由**：多付的钱买到的流量，按单价算比低一档还贵。遇到这种阶梯，直接选它自己最优的那一档。

### 二、价目表逐档相同的品牌

**[全球云](https://clashhubs.net/reviews/quanqiuyun/) 与 [U1S1](https://clashhubs.net/reviews/u1s1/)** 的月付档位价格与流量完全一致：¥100/700GB、¥180/1500GB、¥20/120GB、¥40/300GB。

我们无法确认两者的实际关系，但价目表的完全重合是可观察的事实。**它对选购的影响不在于「哪家更好」，而在于风险：如果你打算买这两家互为备用，那个备用可能是无效的**——共用后端的两家更可能同时出问题。要做真正的双线备份，请从价格结构明显不同的品牌里选第二家。

## 常见问题

### 为什么不提供测速数据？
因为我们没有统一口径的测速体系。测速结果的上限由测试机自身带宽决定，不同机器测出的数字无法横向比较；而单 GB 成本是从公开价目表算出来的，任何人都能复算。**给一个无法复现的数字，不如不给。**

### 单 GB 成本低就一定好吗？
不。它只说明这家在流量单价上更便宜，不代表线路质量。同价位的两家，带宽投入可能差一倍。**它的作用是帮你排除明显不划算的档位**，不是替你做最终决定。

### 分档是怎么定的？
按运营连续性与跑路风险，不按速度。S 档代表持续经营可能性最高的一批。需要说明：**任何机场都可能停服**，分档只是概率判断。

### 榜单顺序会因为合作关系改变吗？
**上面这张表不会**——它由价格与流量算出，我们无法调整。但网站首页有一个单独的「编辑推荐位」区块，那个**包含与部分品牌的合作关系**，已在页面上标明。两者是分开的。

### 表里的价格多久更新一次？
手工维护，没有自动抓取。每个数字都是有人打开官网订阅页录进去的，**因此一定存在滞后**。下单前请以结算页金额为准，发现过期请开 issue。
